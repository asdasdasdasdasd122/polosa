# Полоса — Midnight Run

Браузерная 3D-игра: три полосы, объезд машин, монетки, нитро и полёт с крыльями. Три жизни: третье столкновение завершает заезд.

В архиве находится последняя опубликованная версия игры с оптимизацией для телефонов. Установка зависимостей и сборка не нужны. Все модели, текстуры и библиотеки включены; внешние CDN для запуска не требуются.

## Загрузка на GitHub

1. Распакуйте ZIP на компьютере.
2. Откройте https://github.com/new и создайте репозиторий, например `polosa`. Для бесплатного GitHub Pages выберите Public.
3. В репозитории нажмите Add file → Upload files. В пустом репозитории можно нажать uploading an existing file.
4. Перетащите всё содержимое распакованного архива: файлы и папки `assets` и `vendor`. Сохраните структуру папок. Загрузите и `.nojekyll`; на macOS скрытые файлы можно показать сочетанием Cmd + Shift + .
5. Убедитесь, что `index.html` лежит прямо в корне репозитория, затем нажмите Commit changes. Сам ZIP загружать не нужно.

## Запуск по ссылке через GitHub Pages

1. Откройте Settings → Pages.
2. В Source выберите Deploy from a branch.
3. Выберите ветку main и папку /(root), нажмите Save.
4. Дождитесь публикации. Адрес появится в Settings → Pages:
   `https://ВАШ_ЛОГИН.github.io/polosa/`

Название последней части адреса соответствует названию репозитория. Если нужны только исходные файлы на GitHub, включать Pages не обязательно.

Документация GitHub:
- https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
- https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Запуск на компьютере

Откройте терминал в папке с `index.html` и запустите локальный HTTP-сервер, например при установленном Python:

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080/ в браузере. Для загрузки JS-модулей и 3D-моделей нужен HTTP-сервер; открытие `index.html` двойным щелчком может не работать.

## Управление

- ← / →, A / D или свайп: смена полосы.
- Shift или N: нитро.
- E: полёт при полном заряде ульты.
- P или пробел: пауза.
- На телефоне доступны экранные кнопки.

## Файлы

- `index.html`: страница игры.
- `app.js`: управление, интерфейс, игровой цикл.
- `engine.js`: движение, столкновения, монеты, способности.
- `renderer.js`, `scene-webgl.js`, `scene3d.js`, `car-models.js`: графика.
- `performance.js`: автоматическая настройка качества.
- CSS-файлы: оформление страницы и игрового интерфейса.
- `assets/`: модели машин, текстуры и сведения об авторах.
- `vendor/`: включённые библиотеки и их лицензии.
